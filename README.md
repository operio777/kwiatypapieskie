# Kwiaciarnia Kwiaty Papieskie – wersja robocza

Strona prezentuje dwa filary oferty: kwiaciarnię (świeże kwiaty, bukiety) oraz znicze i florystykę pogrzebową.

## Zdjęcia
- 15 fotografii produktów z dostarczonego archiwum, przygotowanych w WebP
- 3 zdjęcia sklepu / szyldu / okolicy (ostatnie niewykorzystane w układzie strony, dostępne w katalogu images)
- Galeria produktów przedstawia w większości kompozycje funeralne. Zdjęcia bukietów ze świeżych kwiatów warto dodać osobno.

## Przed publikacją
- Potwierdź dokładny adres kwiaciarni, godziny otwarcia i numer telefonu 663 192 536 (widoczny na szyldzie).
- Ustal zakres sprzedaży wkładów, stroików i usług wykonywanych na zamówienie; popraw opisy, jeśli są niedostępne.
- Dodaj wizytówkę Google i prawdziwy link do trasy dojazdu.
- Utwórz politykę prywatności, jeśli zostaną dodane narzędzia analityczne lub formularze.
- Repozytorium na GitHubie wymaga ręcznego załadowania pełnej paczki lub osobnego przesłania zmian i zdjęć.

## Publikacja
Po sprawdzeniu: GitHub Pages → Settings → Pages → Deploy from a branch → main / root; następnie konfiguracja DNS domeny w OVH.
